# Day 2 — Ticket Analysis

Workshop exercise for the AI Tools Training program (Developer track, Day 2: *Ticket analysis, reproduce & understand*).

## Objective

Practice reading a vague ticket, forming your own understanding first, and then using Claude to find gaps and draft clarifying questions before any code is written.

## The exercise

Analyze five tickets. For each one, write a three-sentence analysis (what it asks, what's ambiguous, first step), ask Claude to review the ticket, then compare Claude's feedback with your own analysis and record what you learned.

> **Note — scope of this exercise**
> - The five tickets are **simulated** software development tickets written for this exercise. They are **not** from the training backlog.
> - The exercise was completed **independently, without a partner**. No partner comparison was done.

## Workflow

For each ticket in [ticket-analysis.md](ticket-analysis.md):

1. Read the ticket description.
2. Write the three-sentence initial analysis **before** asking Claude (already done for all five tickets).
3. Give Claude the ticket and ask it to identify missing gaps and draft clarifying questions.
4. Paste Claude's actual feedback, gaps, and questions into the ticket's placeholders.
5. Compare Claude's feedback with your initial analysis and note what you learned.

## Deliverables checklist

- [x] Initial three-sentence analysis for all five tickets
- [x] Claude's feedback recorded for each ticket
- [x] Missing gaps and clarifying questions recorded for each ticket
- [x] Comparison with initial analysis for each ticket
- [x] Learnings recorded for each ticket
