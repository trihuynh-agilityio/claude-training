# claude-training

Sandbox repo for the [AI Tools Training](https://dojo.agilityio.dev/schedule.html) program (Developer track). All practice work happens here, never on client code.

## Program at a glance

- **15 working days**, full-time, ~6 hours of hands-on work per day plus assigned courses
- **Daily rhythm:** 15-minute morning briefing, hands-on blocks, 10-minute end-of-day standup (what you shipped)
- **Checkpoints:** Days 3, 6, 11, 15

## Schedule

| Phase | Days | Topics |
|---|---|---|
| Week 1: Shared fundamentals | 1–3 | D1 Mental model + Claude basics · D2 Ticket analysis, reproduce & understand · D3 Fix, review, merge ✅ |
| Week 2: Developer track | 4–8 | D4 Install & daily loop · D5 Memory & context · D6 Flagship & parallel ✅ · D7 Skills & plugins · D8 MCP & connectors |
| Week 3: Developer track, deeper | 9–11 | D9 Hooks & automation · D10 Review & quality · D11 Role day ✅ |
| Capstone (cross-functional) | 12–15 | D12 Kickoff & planning · D13 Build · D14 Test & harden · D15 Review, merge, demo ✅ |

✅ = checkpoint day
